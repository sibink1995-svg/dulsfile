# DualPane Files

X-plore സ്റ്റൈൽ ഡ്യുവൽ-പെയ്ൻ ആൻഡ്രോയിഡ് ഫയൽ മാനേജർ (Kotlin, ഒറിജിനൽ കോഡ്).

- രണ്ട് പാനലുകൾ (ടാബ്‌ലെറ്റ്/ലാൻഡ്‌സ്കേപ്പിൽ ഇടത്-വലത്, ഫോൺ പോർട്രെയ്റ്റിൽ മുകളിൽ-താഴെ)
- നടുവിൽ ടൂൾബാർ: Up dir, **Disk map** (ഫോൾഡർ വലിപ്പം treemap ആയി; ബ്ലോക്കിൽ ടാപ്പ് ചെയ്താൽ ഉള്ളിലേക്ക്, ബാക്ക് = മുകളിലേക്ക്), Copy, Move, Rename, Delete, Create ZIP, New folder, New text file, Select all, Show hidden, Sort by, Find, Refresh
- ഫയൽ **ലോങ്ങ് പ്രസ്സ്** ചെയ്താൽ സെലക്ട് ആകും; കോപ്പി/മൂവ് ചെയ്യുമ്പോൾ ഫയൽ *മറ്റേ പാനലിലെ* ഫോൾഡറിലേക്ക് പോകും
- **ട്രീ വ്യൂ**: ഫോൾഡറിൽ ടാപ്പ് ചെയ്താൽ അതിന്റെ ഉള്ളടക്കം തൊട്ടുതാഴെ ഇൻഡന്റ് ചെയ്ത് വിടരും (വീണ്ടും ടാപ്പ് = ചുരുങ്ങും). 📁 ഐക്കണിൽ ടാപ്പ് ചെയ്താൽ ആ ഫോൾഡർ പാനലിന്റെ റൂട്ട് ആകും. അവസാനം ടാപ്പ് ചെയ്ത ഫോൾഡർ ആണ് Copy/Move/New folder-ന്റെ ടാർഗറ്റ്
- ഫയലിൽ ടാപ്പ് ചെയ്താൽ അത് തുറക്കും (ബാക്ക് ബട്ടൺ / Up dir = തുറന്ന ഫോൾഡർ ചുരുക്കി മുകളിലേക്ക്)

- ഓരോ ഫയലിന്റെയും ഫോൾഡറിന്റെയും സൈസ് വലതുവശത്ത് കാണിക്കും (ഫോൾഡർ സൈസ് ബാക്ക്ഗ്രൗണ്ടിൽ കണക്കാക്കും)
- ഇമേജ് വ്യൂവറിൽ ഇടത്/വലത് swipe ചെയ്ത് അടുത്ത ഫോട്ടോ കാണാം; ഡബിൾ ടാപ്പ് = zoom റീസെറ്റ്
- ZIP ഫയലിൽ ടാപ്പ് → Extract / ലിസ്റ്റ് കാണൽ; ഒന്നിലധികം ഫയൽ സെലക്ട് ചെയ്ത് Rename → Batch rename (`File {n}`)
- ഫോട്ടോ/വീഡിയോ thumbnails; ബിൽറ്റ്-ഇൻ ഇമേജ് (pinch zoom), ടെക്സ്റ്റ്, PDF വ്യൂവർ
- **Apps**: ഇൻസ്റ്റാൾ ചെയ്ത ആപ്പുകൾ - Open, APK backup, App info, Uninstall
- **Favorites** (പ്രിയപ്പെട്ട ഫോൾഡറുകൾ), **History** (അവസാനം തുറന്ന ഫോൾഡറുകൾ)
- **Day / Night** ബട്ടൺ: ലൈറ്റ്/ഡാർക്ക് മോഡ് മാറ്റാം (തിരഞ്ഞെടുപ്പ് ഓർത്തുവെക്കും)
- ഏറ്റവും മുകളിൽ ഇന്റേണൽ സ്റ്റോറേജ് Used/Free ബാർ
- പരസ്യങ്ങളില്ല, ട്രാക്കിങ്ങ് ഇല്ല

## GitHub-ൽ APK ഉണ്ടാക്കാൻ
1. GitHub-ൽ പുതിയ repository ഉണ്ടാക്കി ഈ ഫോൾഡറിലെ എല്ലാ ഫയലുകളും (`.github` ഫോൾഡർ ഉൾപ്പെടെ) upload / push ചെയ്യുക.
2. **Actions** ടാബ് → *Build APK* ഓടുന്നത് വരെ കാത്തിരിക്കുക (ഏകദേശം 3-5 മിനിറ്റ്).
3. പൂർത്തിയാകുമ്പോൾ റൺ പേജിന്റെ താഴെ **Artifacts → DualPaneFiles-debug-apk** ഡൗൺലോഡ് ചെയ്ത് APK ഫോണിൽ ഇൻസ്റ്റാൾ ചെയ്യുക.

## ലോക്കലായി ബിൽഡ് ചെയ്യാൻ
Android Studio-യിൽ ഫോൾഡർ തുറക്കുക, അല്ലെങ്കിൽ JDK 17 + Gradle 8.9 ഉണ്ടെങ്കിൽ `gradle assembleDebug`.

## ഇതിൽ ഇല്ലാത്തവ (ചേർക്കാവുന്നവ)
WiFi/FTP server, RAR/7z, SMB/cloud storage, root explorer.

> "All files access" പെർമിഷൻ ആവശ്യമുണ്ട്. Play Store-ൽ പബ്ലിഷ് ചെയ്യാൻ ഇതിന് പ്രത്യേക അനുമതി വേണം; സ്വന്തം ഉപയോഗത്തിന് APK ഇൻസ്റ്റാൾ ചെയ്യാൻ പ്രശ്നമില്ല.
